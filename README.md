# Homer

![Homer smiling](homer.png)

A little Homer for your Mac or Windows desktop.

**[Download Homer](https://homer-downloads.rileyjameson.chatgpt.site)**

- **Mac (macOS 12+, Intel and Apple Silicon):** download the ZIP, open it, and drag Homer into Applications.
- **Windows (Intel/AMD 64-bit):** download and run the installer. No subscription needed.
- Right-click Homer for actions. Drag him to pick him up. His menu bar/system tray icon can show, hide or quit him.
- For future releases, choose **Check for updates…** in Homer's menu.

## Early access

The Mac app is Developer ID-signed and Apple-notarized. If an earlier Mac download would not open, download the current version and replace the old copy in Applications. Windows may show an unverified-publisher warning. If an employer blocks installation, ask IT whether Homer is allowed.
