# Homer

![Homer smiling](homer.png)

A little Homer for your Mac or Windows desktop.

**[Download Homer](https://homer-downloads.rileyjameson.chatgpt.site)**

- **Mac:** download the ZIP, open it, and drag Homer into Applications.
- **Windows (Intel/AMD 64-bit):** download and run the installer. No developer tools or Flow subscription needed.
- Right-click Homer for actions. Drag him to pick him up. His menu bar/system tray icon can show, hide or quit him.
- For future releases, choose **Check for updates…** in Homer's menu.

## Early access
